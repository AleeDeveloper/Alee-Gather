# Changelog

## 0.40.0-wotlk

- Fixed profession detection on Spanish WotLK clients, including `Desollar` / Skinning.
- Added robust profession aliases for English and Spanish clients.
- Added complete Skinning guide support with route maps and target-beast descriptions.
- Added Herbalism route maps using the same guide structure as Mining.
- Added Skinning to the session HUD, profession filter and settings.
- Gas Clouds are identified as an Engineering gathering resource.
- Profession filtering is enabled by default and can be explicitly unlocked in Settings.
- Session loot counters use real stack quantities and continue counting while the timer is paused.
- Added separate World Map, Minimap, Radar and Guide opacity controls.
- Guide can be closed with ESC.
- Adaptive local respawn learning retained for gathered nodes.
- Release cleanup: removed obsolete helper code, empty seed module and unused artwork assets.
